# Jogo da Forca - PHP

Projeto desenvolvido para a disciplina de Programação Back End e Front End.

## Descrição

Este projeto consiste na implementação do jogo da Forca utilizando PHP. A lógica do jogo é processada no servidor e o estado da partida é mantido através de sessões PHP.

## Funcionalidades

- Sorteio aleatório de palavras
- Controle de tentativas
- Verificação de vitória
- Verificação de derrota
- Reinício da partida
- Controle de estado utilizando sessões

## Tecnologias Utilizadas

- PHP 8
- HTML5
- CSS3

## Como Executar

1. Abrir o terminal na pasta do projeto
2. Executar:

```bash
php -S localhost:8000
```

3. Acessar:

```text
http://localhost:8000
```
